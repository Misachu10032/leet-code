# 0125. Valid Palindrome

**Difficulty:** Easy
**Topics:** Two Pointers, String
**Link:** https://leetcode.com/problems/valid-palindrome/

## Approach

Two pointers from both ends, skipping non-alphanumeric chars and comparing lowercase.

## Complexity

- Time: O(n)
- Space: O(1)

## Follow-ups / gotchas

- Cleaning into a new string first is simpler but O(n) space.
